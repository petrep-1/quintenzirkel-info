Deutsch vs. Englisch

Deutsches H = englisches B. Deutsches B = englisches B♭ (Bb). Erhöht wird mit -is (Fis), erniedrigt mit -es (Des), Ausnahmen: Es, As, B. Kleingeschrieben (a, fis) bedeutet im Deutschen Moll.

B-Instrumente

Klarinette, Trompete, Flügelhorn, Tenorsax, Tenorhorn: notiert wird eine große Sekunde (2 Halbtöne) höher als klingend. Klingend C = notiert D.

Es-Instrumente

Altsax, Baritonsax, Es-Horn: notiert eine große Sexte höher (oder kleine Terz tiefer). Klingend C = notiert A.

F-Instrumente

Waldhorn, Englischhorn: notiert eine Quinte höher. Klingend C = notiert G. Oktavlagen (z. B. Tenorsax eine Oktave tiefer klingend) ändern die Notennamen nicht.

Erkennt Akkordzusätze wie m, 7, maj7, sus4, dim, add9 und Basstöne (G/H). Wörter, die keine Akkorde sind, bleiben unverändert.
